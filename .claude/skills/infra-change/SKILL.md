# infra-change — 变更指引

「这件事怎么做、做错了怎么回」。

## 流程

1. 找手册：
   ```bash
   python scripts/infra.py search <动作关键词> --kind runbook --limit 3   # 结果在 手册/
   ```
2. **完整读目标手册全文**（预算 1 条，不截断），向用户复述：前置条件 → 步骤 → 验证 → 回滚。
3. 涉及的资源先 `infra-locate` 确认台账（环境/入口/负责人），避免在错误对象上操作。
4. 执行（见风险分级）。每步做完先验证再进下一步。
5. 收尾：`reference <runbook路径> --in "<变更内容>"`；手册有误/缺节 → 提议更新（走 infra-import 流程）。

## 风险分级（手册 frontmatter 的 risk；未标注按 high）

- **low**：只读或无变更效果的操作，可直接执行。
- **medium**：有变更效果（重启/清理/改配置）——先向用户展示完整步骤清单，**逐项确认**后执行，每步报告结果。
- **high**：生产高危（证书切换/批量主机/数据删除/核心发版）——**只输出人工执行指引**，不代跑；提示用户分步执行、每步验证、准备好回滚。

## 没有手册时

不要凭通用知识直接在生产上操作。改为：
1. 从用户/已有文档收集步骤，用 `python scripts/infra.py new runbook <slug>` 落成草稿；
2. 用户确认步骤无误后，再按上面分级执行；
3. 提醒：这次执行验证后 `verify` 转正，下次就有手册了。
