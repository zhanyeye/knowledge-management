# 运维操作护栏

## 执行前（缺一不可）

1. **定位手册**：`python .wiki/scripts/wiki.py search <操作主题> --type 手册`，完整读取目标手册全文（不受查询预算裁剪）；
2. **风险分级**（frontmatter risk）：
   - `low`：只读/幂等 → 可自动执行；
   - `medium`：向用户展示完整操作清单，确认后执行；
   - `high`（数据库切换、deployer 切换、证书切换、集群变更类）：**必须人工逐项确认**，Agent 只做 预检 → 方案推荐 → 分步执行（每步停下等确认）→ 自动验证；
3. **前置检查**：逐条执行手册前置检查节，任何一条不符 → 中止并报告；
4. **回滚就绪**：确认回滚章节可用、回滚材料（旧配置/备份/快照）存在；
5. **值守**：medium/high 操作告知用户开始时间与预期结束时间。

## 执行中

- 分步执行，每步对照预期输出；偏差 → 停下，不自行"修复"；
- 不执行手册范围外的命令；临时变通先征得确认；
- 留痕：记录实际命令与输出摘要（复盘用）。

## 执行后

1. 执行验证章节，全部通过才算完成；失败 → 立即执行回滚章节并报告；
2. 手册与实际有出入 → 按知识贡献协议更新（进 pending 人审），并 `python .wiki/scripts/wiki.py reference <编号> --in "执行:<操作>"`。

## 硬红线

- 没有 runbook（手册类条目）的 high 风险操作：拒绝执行，先推动沉淀手册；
- 凭据不入库、不回显；
- 删除类命令必须落在回滚覆盖范围内。
