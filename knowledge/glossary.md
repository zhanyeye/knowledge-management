# 术语表（glossary）

> 帮助 agent 与新人对齐语境。释义不确定的标「待确认」，确认后删除标记。

## 网络分区
- **黄区 / 绿区 / 通用区**：内部网络分区。绿区转发代理见 `knowledge/04-网络管理/代理网关/`。（分区边界与访问规则：待确认）
- **IPE**：内部演示/体验环境相关平台（详见 `knowledge/09-业务平台对接/`）。

## 平台与系统
- **HIS**：内部基础服务平台（数据库、API 订阅等能力）。慢 SQL 页面/入口：待确认。
- **ROMA**：资源管理平台（节点纳管/批量删除等）。
- **viewpoint**：执行机资源管理平台（注册、延期、关机清理）。
- **云龙**：容器构建相关平台（API 调用、vpc 对接细节见 `knowledge/03-构建资源管理/云龙/`）。
- **px / PipelineX**：CI 流水线系统（执行资源池、Gate 门禁、minio 缓存）。
- **门禁 Gate**：px 上的代码门禁能力（增量重试等）。
- **deployer / 珊瑚 / FOA / 扶摇 / AI-bom**：业务平台对接对象，见 `knowledge/09-业务平台对接/`。

## 基础设施
- **EKS / Rancher**：K8s 集群管理形态；生产集群清单见 `knowledge/02-k8s资源管理/inventory.yaml`。
- **Helm-CD**：基于 Helm 的微服务发布部署方式。
- **node-agent**：各集群 DaemonSet 形态的节点代理；发版走灰度手册。
- **goLLT**：构建/门禁流程中的时长敏感环节（见 `knowledge/03-构建资源管理/复盘/`）。
