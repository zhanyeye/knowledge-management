# 执行机残留导致构建失败

## 症状
- 表现：构建任务失败，重试依然失败
- 影响面初判：该执行机上的构建任务

## 排查路径

### 1. 重试并观察
- 任务重试一次：同机仍失败 → 怀疑执行机环境问题

### 2. 登机检查脏数据
```bash
df -h                      # 系统盘是否满
du -sh /tmp /usr1 2>/dev/null   # 常见残留目录（TODO：确认完整目录清单）
ls /tmp | head
```

### 3. 手工清理
- 确认残留为构建产物/临时文件后清理；**不确定归属的文件先查再删**
