# 防火墙开通申请

## 目标
为服务间/跨区访问申请防火墙策略开通。

## 适用范围
- 环境：全部网络区
- 前提权限：防火墙申请电子流

## 前置条件
- 梳理好出入站 IP 与端口清单（**逐条列全：源/目的/端口/协议/用途**）

## 操作步骤

1. 梳理出入站 IP/端口
2. 填写防火墙申请电子流（TODO：电子流入口与填写模板）
3. 跟踪审批进度直到开通

## 验证
- 开通后连通性验证：
  ```bash
  nc -zv <目的IP> <端口>
  # 或 telnet <IP> <端口>
  ```

## 回滚
- 按同一流程申请关闭策略

## 常见问题
- 审批驳回：检查用途说明与最小开通原则
- 开通后仍不通：双向都要开（回程端口）
