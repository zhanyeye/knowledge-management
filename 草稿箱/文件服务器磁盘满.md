# 公共/px 文件服务器磁盘满

## 症状
- 表现：应用层写文件失败，人工反馈报错
- 影响面初判：使用该文件服务器的所有应用（TODO：确认受影响服务清单）

## 排查路径

### 1. 登录服务器确认数据盘状态
```bash
df -h          # 确认数据盘是否已满
```

### 2. 逐层定位大文件目录
```bash
du -sh /* 2>/dev/null | sort -rh | head
du -h --max-depth=1 <大目录>   # 逐层下钻
```
