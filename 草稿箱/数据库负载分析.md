# 数据库负载问题分析

## 症状
- 表现：数据库告警（负载高/慢查询多），或业务反馈数据库异常
- 影响面初判：按告警库的范围确认

## 排查路径

### 1A. HIS 数据库
1. 收到数据库告警
2. 到数据库 HIS 页面查慢 SQL（TODO：HIS 慢 SQL 页面入口）
3. 找到慢 SQL 对应的业务方，推动优化

### 1B. 自建数据库
1. 业务应用反馈问题
2. 登录 vm 排查宿主层：
   ```bash
   uptime                    # cpu load
   free -h                   # 内存
   df -h                     # 磁盘
   last | head               # 是否发生过重启
   ```

| 宿主机资源瓶颈 | load/内存/磁盘高 | 扩容或迁移 |
