# 微服务响应时延大（逐层定位）

## 症状
- 表现：微服务接口/请求时延明显变大
- 影响面初判：该服务及其调用方

## 排查路径

### 1. 确认网络链路
- 梳理该服务的完整网络链路（TODO：链路图待建，见 architecture/request-flow/）
- 明确经过哪些 nginx / 代理 / 网关 / 服务

### 2. 二分法逐层过滤统计
- 在关键 nginx/服务日志上按时间段统计耗时，确认耗时集中在哪一层
  ```bash
  # 统计各层 access log 的 RT 分布（TODO：日志路径与字段待确认）
  awk '{print $NF}' access.log | sort | uniq -c
  ```
- 每次二分锁定一半链路，直到定位到慢的节点
