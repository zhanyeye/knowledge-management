# 定位服务部署位置（Rancher 负载 / VM 进程）

## 目标
找到某个服务/负载跑在哪：K8s 部署在哪个集群/命名空间，VM 部署的进程在哪个目录。

## 适用范围
- 环境：全部
- 前提权限：Rancher 访问权 / 目标 VM 登录权

## 前置条件
- 知道服务名/镜像名/进程名（至少其一）

## 操作步骤

### k8s 部署的服务
1. 登录 Rancher（TODO：入口与账号，建 registry 后补链接）
2. 挨个集群/命名空间搜索服务名（TODO：有无全局搜索入口待确认）

### VM 部署的服务
1. 登录 vm，通过进程名/端口找 pid：
   ```bash
   ps -ef | grep <关键字>
   ss -lntp | grep <端口>
   ```
2. 到 /proc/$pid 找进程二进制所在目录与命令参数：
   ```bash
   ls -l /proc/$PID/exe        # 二进制位置
   cat /proc/$PID/cmdline | tr '\0' ' '   # 完整启动参数
   ```
3. 复杂场景需要找父子进程：
   ```bash
   cat /proc/$PID/status | grep PPid
   ```

## 验证
- 找到的负载/进程与目标服务名、端口吻合

## 回滚
- 纯查找操作，无需回滚

## 常见问题
- 找不到：确认服务名拼写/别名，或问 owner（registry）
